# 10 — Mockups

## Propósito

Documentar las propuestas visuales de alta fidelidad para las interfaces de VIGIA.

## Contenido esperado

Incluir pantallas, variantes de tema o estado, componentes relevantes y notas de interacción cuando estén definidos. Este directorio contiene plantillas o diseños reales únicamente cuando existan y puedan ser identificados como tales.

## Formato y ubicación

Guardar exportaciones en `PDF`, `PNG` o `SVG`, junto con los archivos fuente editables, dentro de este directorio.
