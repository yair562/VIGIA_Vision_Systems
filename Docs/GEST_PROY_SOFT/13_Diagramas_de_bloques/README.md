# 13 — Diagramas de Bloques

## Propósito

Documentar la descomposición funcional y las relaciones entre los bloques de software, hardware, comunicación y operación que se definan para VIGIA.

## Contenido esperado

Incluir bloques, interfaces, flujos de información o energía, límites y nivel de detalle de cada diagrama. Las decisiones no confirmadas deben marcarse como `TBD`.

## Formato y ubicación

Guardar fuentes editables y exportaciones en `PDF`, `SVG` o `PNG` dentro de este directorio.
