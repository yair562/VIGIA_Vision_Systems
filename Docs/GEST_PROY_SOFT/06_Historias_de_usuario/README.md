## 1. Descripción del Entregable

Este directorio concentra las historias de usuario redactadas para el caso de uso rector (*Caseta Inteligente de Acceso Vehicular*), estructuradas bajo el patrón:

\textbf{Como } [\text{Rol}] \quad \textbf{Quiero } [\text{Acción / Capacidad}] \quad \textbf{Para } [\text{Beneficio / Valor}]

y evaluadas mediante criterios de aceptación en formato $\text{Dado / Cuando / Entonces } (\textit{Given-When-Then})$.
