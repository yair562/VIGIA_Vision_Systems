# 11 — Diagrama de Flujo

## Propósito

Representar las etapas, decisiones y resultados del flujo operativo que se documente para VIGIA.

## Contenido esperado

Incluir el proceso representado, sus entradas y salidas, decisiones, excepciones y leyenda. No se considera completado hasta contar con un diagrama aprobado o una evidencia equivalente.

## Formato y ubicación

Usar una fuente editable y una exportación en `PDF`, `SVG` o `PNG`. Guardar ambos artefactos en este directorio.
