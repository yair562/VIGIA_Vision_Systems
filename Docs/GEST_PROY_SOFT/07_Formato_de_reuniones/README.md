## 1. Descripción del Entregable

Este entregable comprende el formato oficial completo de minutas y actas de reunión institucional utilizado para documentar los acuerdos, compromisos, revisión de avances y decisiones técnicas tomadas por el equipo de VIGIA Vision Systems.

### Secciones Integradas en el Formato:
1. **Datos Generales:** Fecha, hora, lugar/enlace, objetivo de la sesión y tipo de reunión (Sprint Planning, Daily, Review, Retrospectiva).
2. **Registro de Asistencia:** Control de participantes, puestos y firmas.
3. **Orden del Día:** Puntos tratados durante la sesión.
4. **Acuerdos y Compromisos:** Tareas acordadas, responsables específicos y fechas de entrega.
5. **Seguimiento de Asuntos Pendientes:** Estado de acuerdos previos.
