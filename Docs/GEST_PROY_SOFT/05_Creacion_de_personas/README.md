## 1. Descripción del Entregable

Este entregable define los arquetipos representativos de los usuarios y operadores que interactúan directa e indirectamente con la plataforma VIGIA:

1. **Operador / Guardia de Caseta:**
   * *Objetivo:* Supervisar los carriles, visualizar el flujo en tiempo real y disponer de controles sencillos de mando manual ante contingencias.
   * *Puntos de dolor:* Interfaces sobrecargadas, retrasos en la respuesta de barreras y falta de alertas claras.
2. **Conductor / Residente / Visitante Autorizado:**
   * *Objetivo:* Ingresar a las instalaciones de forma rápida, sin detenerse a mostrar credenciales físicas ni interactuar manualmente.
   * *Puntos de dolor:* Lecturas fallidas de placa y tiempos de espera prolongados.
3. **Administrador de Seguridad / Instalaciones:**
   * *Objetivo:* Gestionar listas de acceso, consultar bitácoras de eventos con evidencia fotográfica y asegurar el cumplimiento de políticas de seguridad.
