# 12 — Diagrama de Casos de Uso

## Propósito

Describir las interacciones entre los actores y las funciones que VIGIA deba proporcionar.

## Contenido esperado

Documentar actores, casos de uso, límites del sistema y relaciones (`include`, `extend` o generalización) cuando apliquen. La nomenclatura debe coincidir con los requisitos e historias de usuario existentes.

## Formato y ubicación

Guardar el archivo fuente del modelado y una exportación en `PDF`, `SVG` o `PNG` en este directorio.
