# 16 — Fichas Técnicas

## Propósito

Describir de forma trazable los componentes, herramientas, interfaces o recursos técnicos utilizados o considerados para VIGIA.

## Contenido esperado

Cada ficha debe identificar el elemento, versión o modelo, función, especificaciones relevantes, compatibilidad, fuente de información y estado. Los datos no confirmados deben marcarse como `TBD`.

## Formato y ubicación

Guardar fichas en `Markdown`, `PDF` o el formato técnico acordado, dentro de este directorio.
