# 19 — Plan de Calidad

## Propósito

Organizar los criterios y evidencias para verificar la calidad de los entregables y del sistema VIGIA.

## Referencia existente

La guía institucional disponible se conserva sin duplicarla en [`Docs/Referencias/Plan_de_calidad.pdf`](../../Referencias/Plan_de_calidad.pdf). Es material de consulta y no demuestra por sí sola que se hayan ejecutado pruebas o aceptado resultados.

## Estructura esperada

Para cada criterio documentar: criterio de calidad, método de verificación, criterio de aceptación, responsable, fecha o versión aplicable y evidencia. Los resultados no comprobados deben permanecer como `TBD`.
