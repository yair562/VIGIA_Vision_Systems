# 09 — Wireframes

## Propósito

Definir la estructura y distribución de las pantallas de VIGIA antes de aplicar estilos visuales.

## Contenido esperado

Incluir wireframes de las vistas relevantes, sus estados principales, navegación y anotaciones funcionales. Los responsables y el estado de cada pantalla deben quedar identificados sin asumir que el diseño está terminado.

## Formato y ubicación

Usar archivos editables o exportaciones en `PDF`, `PNG`, `SVG` u otro formato acordado por el equipo. Guardar los artefactos y sus fuentes en este directorio.
