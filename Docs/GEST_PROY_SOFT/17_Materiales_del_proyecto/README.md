# 17 — Materiales del Proyecto

## Propósito

Mantener el inventario de materiales y recursos necesarios para construir, operar o demostrar el proyecto VIGIA.

## Contenido esperado

Registrar descripción, cantidad requerida, unidad, propósito, fuente, disponibilidad y estado de cada material. Separar materiales confirmados de necesidades pendientes.

## Formato y ubicación

Usar una tabla en `Markdown` o una hoja de cálculo exportada a `PDF`. Guardar el inventario y sus evidencias en este directorio.
