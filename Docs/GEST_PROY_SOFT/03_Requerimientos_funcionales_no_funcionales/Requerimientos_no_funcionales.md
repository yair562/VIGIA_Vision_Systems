## 1. Catálogo de Requerimientos No Funcionales (RNF)

| ID | Requerimiento no funcional |
| :---: | :--- |
| **RNF-01** | El sistema deberá implementar mecanismos de autenticación y control de acceso para proteger las funciones y la información disponible. |
| **RNF-02** | El sistema deberá proteger la información almacenada contra accesos, modificaciones o eliminaciones no autorizadas. |
| **RNF-03** | El sistema deberá mantener la integridad y consistencia de los registros de personas, vehículos y eventos relacionados. |
| **RNF-04** | La interfaz deberá presentar la información de supervisión de manera clara, consistente y comprensible para el personal autorizado. |
| **RNF-05** | El sistema deberá registrar errores y fallos relevantes que permitan facilitar su diagnóstico y mantenimiento. |
| **RNF-06** | El sistema deberá mantener una arquitectura modular que permita incorporar nuevas capacidades de visión artificial sin requerir el rediseño completo del sistema. |
| **RNF-07** | El sistema deberá permitir realizar actualizaciones y mantenimiento de sus componentes de manera controlada. |
| **RNF-08** | El sistema deberá contar con mecanismos básicos de respaldo y recuperación de los registros almacenados. |
| **RNF-09** | El sistema deberá utilizar únicamente la información personal necesaria para proporcionar las funciones definidas dentro de su alcance. |
