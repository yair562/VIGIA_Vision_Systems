## 1. Catálogo de Requerimientos No Funcionales (RNF)

| ID | Requerimiento no funcional |
| :---: | :--- |
| **RNF-01** | Utilizar autenticación mediante usuario y contraseña para controlar el acceso al sistema. |
| **RNF-02** | Asignar permisos de acceso de acuerdo con el rol de cada usuario. |
| **RNF-03** | Restringir el acceso a la información de personas, vehículos y eventos a los usuarios que cuenten con los permisos correspondientes. |
| **RNF-04** | Almacenar las contraseñas mediante un mecanismo de hash seguro que impida conservarlas en texto plano. |
| **RNF-05** | Proteger la información almacenada mediante mecanismos de cifrado para evitar accesos no autorizados. |
| **RNF-06** | Mantener la integridad de los registros de personas, vehículos y eventos mediante controles que eviten modificaciones no autorizadas. |
| **RNF-07** | Presentar la información de supervisión mediante una interfaz clara, consistente y comprensible para el personal autorizado. |
| **RNF-08** | Registrar los errores y fallos relevantes del sistema para facilitar su diagnóstico y mantenimiento. |
| **RNF-09** | Mantener una arquitectura modular que permita incorporar nuevos componentes de procesamiento o visión artificial sin modificar completamente el sistema. |
| **RNF-10** | Realizar copias de respaldo de los registros almacenados para permitir su recuperación ante pérdida de información. |
| **RNF-11** | Recuperar los registros almacenados a partir de las copias de respaldo disponibles. |
| **RNF-12** | Limitar la recopilación de datos personales a la información necesaria para ejecutar las funciones definidas dentro del alcance de VIGIA. |
