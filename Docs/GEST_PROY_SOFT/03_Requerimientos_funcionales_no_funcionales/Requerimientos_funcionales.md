## 1. Catálogo de Requerimientos Funcionales (RF)

| ID | Requerimiento funcional |
| :---: | :--- |
| **RF-01** | El sistema deberá capturar información visual mediante las cámaras configuradas para la supervisión del entorno. |
| **RF-02** | El sistema deberá procesar la información visual mediante los mecanismos de visión artificial definidos para VIGIA. |
| **RF-03** | El sistema deberá detectar los elementos y eventos definidos dentro del alcance de supervisión de VIGIA. |
| **RF-04** | El sistema deberá registrar los eventos detectados junto con la fecha, hora y demás información disponible asociada al evento. |
| **RF-05** | El sistema deberá conservar evidencia visual asociada a los eventos registrados cuando ésta se encuentre disponible. |
| **RF-06** | El sistema deberá permitir registrar y administrar información de alumnos, trabajadores y vehículos contemplados dentro del alcance del sistema. |
| **RF-07** | El sistema deberá relacionar un vehículo detectado con una persona registrada cuando exista una coincidencia con la información almacenada. |
| **RF-08** | El sistema deberá indicar cuando un vehículo o evento detectado no pueda ser relacionado con un registro existente. |
| **RF-09** | El sistema deberá almacenar los eventos registrados para permitir su consulta posterior. |
| **RF-10** | El sistema deberá permitir consultar los eventos y la información relacionada con personas y vehículos registrados. |
| **RF-11** | El sistema deberá proporcionar información que permita al personal autorizado identificar eventos de interés para la seguridad preventiva. |
| **RF-12** | El sistema deberá proporcionar una señal visual asociada al resultado de determinados eventos, de acuerdo con las reglas de operación definidas. |
