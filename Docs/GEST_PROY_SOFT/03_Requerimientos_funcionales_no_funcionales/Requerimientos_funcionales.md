## 1. Catálogo de Requerimientos Funcionales (RF)

| ID | Requerimiento funcional |
| :---: | :--- |
| **RF-01** | Capturar imágenes del entorno mediante las cámaras configuradas en VIGIA. |
| **RF-02** | Analizar las imágenes capturadas mediante los mecanismos de visión artificial integrados en VIGIA. |
| **RF-03** | Detectar los elementos y eventos definidos para la supervisión del entorno. |
| **RF-04** | Registrar cada evento detectado con su fecha y hora de detección. |
| **RF-05** | Asociar evidencia visual a cada evento detectado. |
| **RF-06** | Almacenar la evidencia visual asociada a cada evento detectado. |
| **RF-07** | Registrar los datos de alumnos, trabajadores y vehículos contemplados dentro del alcance de VIGIA. |
| **RF-08** | Administrar los registros de alumnos, trabajadores y vehículos. |
| **RF-09** | Asociar un vehículo detectado con una persona registrada cuando los datos detectados coincidan con un registro almacenado. |
| **RF-10** | Identificar los vehículos y eventos detectados que no coincidan con los registros almacenados. |
| **RF-11** | Consultar los eventos registrados y los datos relacionados con personas y vehículos. |
| **RF-12** | Mostrar al personal autorizado los eventos que cumplan las condiciones establecidas para la supervisión preventiva. |
| **RF-13** | Activar una señal visual cuando un evento cumpla las condiciones establecidas para su activación. |
