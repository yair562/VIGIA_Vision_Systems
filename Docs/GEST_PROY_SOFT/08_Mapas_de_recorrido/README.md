## 1. Descripción del Entregable

Este entregable documenta el recorrido del usuario (*Customer / User Journey*) a través de las diferentes fases del ciclo de acceso vehicular gobernado por VIGIA:

1. **Aproximación:** El conductor arriba al carril de acceso; el sistema detecta la presencia y captura el frame de video.
2. **Identificación:** Extracción alfanumérica de la matrícula y validación en el motor de reglas.
3. **Decisión y Señalización:** Conmutación de señal visual (semáforo Verde/Rojo) y comando a la barrera electromecánica.
4. **Cruce y Verificación Sensorial:** Paso físico del vehículo validado por sensores de despeje en lazo cerrado.
5. **Cierre y Registro:** Descenso seguro de la barrera y almacenamiento de la evidencia fotográfica y log de auditoría.
