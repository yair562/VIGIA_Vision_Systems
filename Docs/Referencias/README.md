# Referencias y Soporte Institucional

**Proyecto:** VIGIA Vision Systems  
**Área:** Documentación de Referencia y Soporte Académico / Institucional  

---

## 1. Propósito de este Directorio

El directorio `Docs/Referencias/` alberga los documentos institucionales, normativos y de referencia externa que sirven como guía metodológica y marco de calidad para el proyecto VIGIA Vision Systems.

Estos archivos se mantienen fuera del directorio de entregables oficiales (`Docs/GEST_PROY_SOFT/`) para asegurar una estricta separación entre los entregables de trabajo del equipo y los materiales de soporte / plantillas institucionales.

---

## 2. Contenido del Directorio

| Archivo | Tipo | Descripción |
| :--- | :--- | :--- |
| **`Memoria_Tecnica_de_proyecto.pdf`** | Guía / Marco Metodológico | Guía institucional para la elaboración de la memoria técnica de proyectos de ingeniería y software. |
| **`Plan_de_calidad.pdf`** | Guía / Marco de Calidad | Lineamientos y estructura de referencia para el aseguramiento de calidad del software y hardware. |

---

## 3. Estado y Vigencia

* Estos documentos son de **consulta y referencia metodológica**.
* No sustituyen los entregables técnicos ni de gestión del proyecto VIGIA documentados en `Docs/` y `Docs/GEST_PROY_SOFT/`.
